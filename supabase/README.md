# Supabase (Paso 1)

Esta carpeta deja preparado un punto de partida para el esquema del MVP.

## Pendiente de configurar
- Crear proyecto en Supabase
- Completar `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` y `SUPABASE_SERVICE_ROLE_KEY` en `.env.local`
- Aplicar migraciones (CLI o SQL editor)

## Prueba local
- Ejecutar `npm run dev`
- Abrir `/api/diagnostico/paso-1`
